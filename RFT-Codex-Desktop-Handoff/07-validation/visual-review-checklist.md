# Visual review checklist — actual app, source-informed

## References
- [ ] All 21 original PNGs visually inspected and classified.
- [ ] Existing mockup variants reconciled; no unsupported claims about approved exact frames.
- [ ] Extracted brand/account icons are clear, correctly sized, lawful to use; originals preserved.
- [ ] Lucide used consistently for generic UI actions; icons have labels where needed.

## UI quality
- [ ] Public hero original, informative, calm; no filler slogans or fake testimonials.
- [ ] Dashboard money hierarchy clear (net flow vs estimated balance), large readable numbers.
- [ ] Add transaction works quickly without overly dense form.
- [ ] Navigation remains reachable at 320px mobile and tablet/desktop.
- [ ] Typography consistent, purposeful alignment/spacing, appropriate contrast and radii.
- [ ] Charts explain real math and remain accessible without solely relying on color.
- [ ] Empty, loading, validation error, session-expired, MFA, no-network and deletion states reviewed.
- [ ] EN/BM layout checked with long strings and currency formatting.
- [ ] Animations brief, purposeful, reduced-motion enabled; no generic sequential fades or gratuitous glass/gradients.
- [ ] Keyboard/assistive tech and safe-area behavior checked; no clipped core action.

## Evidence
Capture actual browser screenshots for homepage, dashboard, add, activity, accounts, insights, settings, login/MFA at narrow/mobile/tablet/desktop. Note viewport, browser, build SHA, mockup reference, observed defect, fix and retest. Never present conceptual PNG mockups as screenshots of a functioning implementation.
