## Design contract after review

Canvas #F7F7F4; surface #FFFFFF; ink #173431; secondary #536660; primary #17665E; subtle #E8F1EC; expense #A43C36. DM Sans is locally hosted. No finance totals appear as real user data until authenticated persistence exists. The public preview uses clearly labeled synthetic examples rendered as actual UI.

Mobile: comfortable 16px body and 44px controls, bottom Home/Activity/Insights/Settings plus separate Add. Desktop: navigation rail and readable content width. Warm teal balance panel supplies the main visual identity; use open rows/dividers for history and avoid identical cards for every fact.

Originals are references, not functional screenshots. Browser QA paths will be appended only after capture.
